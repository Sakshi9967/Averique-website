AVERIQ – Decor that Speaks Divine
AVERIQ is a static front-end website for a spiritual and divine home decor brand.
The website showcases product categories, best-selling products, special offers, and contact information.

Project Overview
This project is built using HTML5 and CSS3.
It includes a responsive layout, animated hero section, product grid, and a styled footer.

Features Implemented
•	Sticky header with navigation links
•	Hero section with background image
•	Brand title and tagline: "Decor that Speaks Divine"
•	Animated "Shop Now" button
•	Floating particle animation in hero section
